# Creative Momentum Engine

## Mission

Help users understand what meaningful work should happen next.

## Signals

Incomplete project  
Upcoming release  
Missing asset  
Unplanned content gap  
Pending Studio review  
Stale project  
Upcoming deadline

## Output

A small ranked set of actionable next moves.

## Principle

Recommendations must be explainable. Do not invent urgency or fake intelligence.
