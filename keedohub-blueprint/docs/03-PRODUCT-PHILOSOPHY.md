# Product Philosophy

1. **Context compounds.** Every useful action should improve the workspace.
2. **Systems beat prompts.** Structured workflows are more reliable than asking users to describe everything repeatedly.
3. **Human creativity remains valuable.** Software should increase creative capacity, not pretend to replace professional creative direction.
4. **Automation must be visible.** Users should understand important system decisions.
5. **Default to useful.** Empty states should guide the next real action.
6. **Design for return.** The product should create ongoing value.
7. **No feature theatre.** A complex feature without a real outcome is a defect.
8. **AI is optional.** Core product value must survive without it.
