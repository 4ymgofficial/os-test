# MVP Scope

## MVP goal

Prove that Keedohub can become a useful creative workspace, starting with Artist OS.

## Included

- Auth
- Workspace
- Creative identity
- Asset library
- Projects
- Artist profile
- Music/release records
- Release workspace
- Content library
- Content planning
- Studio request
- Basic service project tracking
- Notifications
- Search
- Mobile-first app shell

## Excluded from MVP

- Full enterprise team administration
- Advanced predictive analytics
- Multi-provider AI orchestration
- Complex social publishing integrations
- Microservices
- Native mobile applications
