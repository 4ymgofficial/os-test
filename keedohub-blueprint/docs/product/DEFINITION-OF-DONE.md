# Definition of Done

A feature is done when:

- User problem is documented.
- UX flow is documented.
- Data model is defined.
- Permissions are defined.
- Loading, empty and error states exist.
- Mobile behavior is defined.
- Accessibility is considered.
- Server authorization exists.
- Critical logic has tests.
- Analytics/events are defined where useful.
- Documentation is updated.
- Feature works with real persisted data.
- No placeholder or fake success states remain.
