# ADR-004: AI as a Subsystem

## Decision

AI is optional and subordinate to Keedohub's product engines.

## Reason

Keedohub's differentiation is its programmed creative operating model, not access to a generic language model.

## Requirements

AI features must:
- have a documented user problem
- operate within workspace permissions
- receive only required context
- have predictable fallbacks
- expose appropriate uncertainty
- never replace deterministic rules where deterministic rules are sufficient
