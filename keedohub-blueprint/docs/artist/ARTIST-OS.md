# Artist OS

## Mission

Artist OS helps independent artists manage the creative work surrounding their music so releases do not lose momentum.

## Core journey

Artist → Music → Release → Assets → Content → Promotion → Audience → Data → Next Move

## Modules

- Artist identity
- Music library
- Release workspace
- Content Engine
- EPK
- Lyrics
- Asset Library
- Brand Kit
- Tasks
- Timeline
- Studio Requests

## Product rule

Artist OS is an operating environment, not a chatbot and not a social media scheduler.
