# Workspace System

## Purpose

A workspace is a user's persistent creative environment.

## Workspace contains

Identity  
Brand system  
Assets  
Projects  
Releases  
Content  
Services  
Activity  
Settings

## Workspace types

Personal workspace  
Team workspace  
Client workspace  
Keedohub internal workspace

## Membership

Membership defines role, permissions and workspace access.

## Switching

Users may have multiple workspaces. Context must be obvious and safe when switching.
