# Keedohub — Creative Operating System

> **Keedohub is where creative work lives, moves, and gets done.**

Keedohub is a programmed Creative Operating System for artists, brands, businesses, creators and creative teams.

It is not an AI chatbot and it is not an agency website with a dashboard attached. It combines persistent creative workspaces, deterministic creative workflows, content and release engines, asset/project infrastructure, and optional human creative services.

## Product pillars

- Keedohub Core
- Artist OS
- Brand OS
- Business OS
- Creator OS
- Keedohub Studio
- Creative Engines
- Optional Intelligence Layer

## Build rule

**Documentation first. Code second.**

The `docs/` directory is the product source of truth. No major feature should be implemented until its problem, workflow, requirements, data, permissions and acceptance criteria are documented.

## Non-negotiables

- Next.js App Router, not Vite or Create React App.
- TypeScript-first.
- Mobile-first.
- Keedohub red/gold/black identity.
- AI is a subsystem, never the product identity.
- Programmed/domain logic is preferred where rules can solve the problem.
- Modular monolith first.
- User data and creative assets are protected by default.
- Every feature must solve a documented problem.

## Core loop

**Identity → Create → Organize → Produce → Release → Promote → Learn → Next Move**
